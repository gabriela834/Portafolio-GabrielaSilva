## Cómo verlo localmente

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Abre `index.html` con la extensión **Live Server** o ábrelo directamente en un navegador.

## Publicación en GitHub Pages

1. Sube los archivos del proyecto a un repositorio de GitHub.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama que contiene el sitio y la carpeta `/ (root)`.
5. Guarda y espera a que GitHub Pages publique el sitio. La dirección aparecerá en la sección **Pages**.
